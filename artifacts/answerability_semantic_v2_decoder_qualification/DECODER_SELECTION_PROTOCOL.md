# XGrammar 0.2.8 selection protocol

The owner selected exactly XGrammar 0.2.8 before decoder qualification. Selection rationale: advertised Hugging Face Transformers integration, JSON Schema constrained decoding, Qwen compatibility, Windows and CPU support, and a CPython 3.12 Windows AMD64 wheel. These are selection premises, not qualification findings.

Selection did not use DEVELOPMENT results, HELD_OUT results or V2 semantic qualification performance. No competing decoder was benchmarked. Only the exact owner-authorized wheel and SHA are permitted. Missing dependencies or incompatible frozen versions require DECODER_QUALIFICATION_BLOCKED, without automatic dependency resolution. No model or semantic smoke work begins before package preconditions pass.
