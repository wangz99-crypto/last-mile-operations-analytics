# Unchanged deterministic adapter

The frozen semantic_gate_v2.py canonicalize/adapt_response path and its V1 consistency parser remain byte-identical and are not executed in this phase. Their source identities and rank mapping contract are recorded in HISTORICAL_INTEGRITY_RECEIPT.json.

Six separately counted obligations remain ADAPTER_ENFORCED: actual supplied-rank membership; exact lexical integer rank tokens; strictly ascending unique ranks; exact rank-to-canonical policy identity mapping without retrieval/guessing or changing model decision fields; frozen semantic cross-field/status-reference consistency; final existing GateOutput construction. Redundant existing structural checks in the adapter stay unchanged, but none can replace the mandatory upstream exact validation.

No raw-schema occurrence is assigned exclusively to the adapter. The matrix reports zero adapter-owned raw-schema occurrences and six additional adapter obligations, so these denominators are never conflated. Static schema rank bounds 1-10 do not replace actual GateInput membership. The adapter continues to reject unsorted ranks, float/exponent/bool rank tokens and invalid mapping/context even if the static schema passes.

Only decoder PASS + JSON parse PASS + exact schema PASS can invoke the adapter. The existing adapter accepts the original raw bytes and validated GateInput; do not feed it repaired or normalized JSON. Its internal canonical policy mapping and audit serialization happen only after validation and are not a repair of raw generated bytes. Adapter failure yields ADAPTER_STRUCTURAL_REJECT/STRUCTURAL_INVALID (or a separate candidate-error channel on unexpected exception), never GateOutput or semantic credit.

GateInput, GateOutput, scoring and benchmark labels are unchanged. No rich benchmark object may enter the future candidate; existing input boundaries remain frozen.
