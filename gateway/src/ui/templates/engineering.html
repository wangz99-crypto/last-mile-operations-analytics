Design decision

  • Rules decide operational state.
  • Policy sections provide traceable evidence.
  • The LLM was tested as a semantic judge and failed qualification.
  • Therefore, humans retain final action authority.

Structured output does not guarantee correct reasoning.

We evaluated the small model before delegating policy decisions to it. It did not meet the pre-registered semantic-support thresholds. This portfolio design keeps business rules deterministic and final operational decisions with a human.

What this workspace runs

  • Structured synthetic shipment facts
  • Python deterministic triage engine
  • Exact SOP section lookup from rule references
  • Rule-based explanations and human review

No LLM or embedding model runs in this workspace.

What the experiments established

  • ✓ Deterministic execution and policy evidence lookup
  • ✓ Decoder, exact schema validator and adapter qualification
  • ✓ End-to-end constrained model runtime in smoke tests
  • ✗ Small-model semantic support judgment
  • ✗ Reliable semantic evidence grounding

Architecture and implementation details

Structured facts → deterministic rules → exact SOP retrieval → evidence-aware presentation → human review.

FastAPI serves plain HTML, CSS and JavaScript. Analysis uses the existing triage_snapshot, SectionStore and retrieve_case_sections interfaces. Policy hashes and stable section identities are checked before recommendations are returned. Retrieval errors stop analysis instead of substituting policy text.

The separate research stack includes BGE embeddings, lexical retrieval, RRF, constrained decoding and JSON Schema Draft 2020-12 validation. Those experiments remain frozen; they are not invoked by this demo.
