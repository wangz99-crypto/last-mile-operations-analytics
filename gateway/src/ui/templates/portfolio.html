Action status

Unit: shipment · one overall action each

How this metric is defined

Count distinct shipments by the engine's overall action. Shipment-wide blockers require review; otherwise the order is ready to escalate, needs review, monitor, then normal.

Counts describe this full synthetic snapshot only. Queue filters and local human decisions do not change the engine's recommendations.

Review gaps

Unit: shipments affected per gap group

A gap may affect one judgment without blocking the whole shipment.

How this metric is defined

Group actual review blockers by the judgment they affect: delivery promise, tracking history, attempt history/identity, or address state. Count each shipment once per group, even if multiple blockers apply.

A shipment can appear in several groups; do not add these counts as a shipment total. Gaps do not establish a root cause or prove that an issue occurred.

Longest-running confirmed issues

Unit: shipment · longest confirmed issue age

How this metric is defined

For each shipment, take the longest engine-derived age among confirmed issues with a known start. Sort longest first, then shipment ID. Normal checks and unknown ages are excluded.

Unknown starts count shipments with at least one unresolved or confirmed issue check whose start cannot be established. They can overlap the ranking; an unresolved check is not proof of an issue. This is not queue waiting time, backlog or team performance.
